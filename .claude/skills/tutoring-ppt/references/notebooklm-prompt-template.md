# S4 NotebookLM 提示詞模板

每次上課產一份，檔名 `第N次上課_提示詞.md`。
每份**完全獨立、自帶全部內容**，不可出現「同上」「見前一份」「延續」。

---

## 使用者的實際操作方式（決定了整個格式）

```
【一】詳盡逐頁設計 → 貼進 NotebookLM 當「資料來源」
【二】簡短指令     → 貼進「提示詞」欄位，要它照那份來源做
```

所以每份檔案**有且只有兩個大區塊**，各自能整段複製。

**產出是連續圖片／PDF，沒有備註欄。**
→ **絕對不可以有「講者備註」欄位**，也不可以用「備註」「補充說明」「教學提示」等別名把它偷渡回來。
原本會放在備註的教學細節，重要的就併進〈內容排版〉的條列，其餘直接刪掉。

---

## 逐頁格式（每頁只有四個欄位，不多不少）

````markdown
### 第 N 頁
- **課本頁數**：P.XX
- **內容排版**：
  - 【標題】〈≤14 字〉
  - 【主文】〈一句話 ≤30 字；沒有就省略這行〉
  - 【條列】
    1. 〈≤20 字〉
    2. 〈≤20 字〉
    3. 〈≤20 字〉
- **插圖引用**：〈畫面繪製描述：有什麼元素、怎麼排、什麼顏色〉（引用課本 P.XX 圖XX-X）
````

### 欄位鐵律

- 四欄順序固定：**頁數 → 課本頁數 → 內容排版 → 插圖引用**
- 標題 ≤14 字；條列最多 4 條、每條 ≤20 字；主文最多一句 ≤30 字
- 字少是硬要求 —— NotebookLM 的中文字是算圖「畫」出來的，字多就糊
- 沒有插圖的頁，〈插圖引用〉寫「無」
- 每一頁都要標課本頁數；複習頁橫跨多頁就寫 P.XX、P.XX
- 小試身手題目與選項**逐字照抄**，不改寫、不簡化、**不給答案**

## 檔案骨架

````markdown
# 〈單元名〉‧ 第N次上課 ‧ NotebookLM 簡報提示詞

> 用法：【一】整段複製貼進 NotebookLM 當「來源」→【二】另外複製貼進「提示詞」欄位 → 格式選 Presenter Slides、語言繁體中文 → 生成

---

# 【一】資料來源文件 ← 整段複製，貼進 NotebookLM 當「來源」

## 〈單元名〉第N次上課 ‧ 逐頁設計（共 20 頁）

### 第 1 頁
- **課本頁數**：P.38
- **內容排版**：
  - 【標題】澆水就復活了
  - 【條列】
    1. 根吸收土壤裡的水分
    2. 莖把水送到植物體全身
- **插圖引用**：三格連續畫面，以綠色箭頭相連——左：盆栽枯萎下垂、葉片捲曲發黃；中：水壺往盆裡澆水；右：同一盆挺立翠綠、黃花朝上。（引用課本 P.38 圖38-1）

### 第 2 頁
（同上結構，一路寫到第 20 頁，一頁都不能省略）

**頁數檢查**：第 1 頁 – 第 20 頁，連續無跳號，共 20 頁 ✓

---

# 【二】提示詞 ← 這段另外複製，貼進「提示詞」欄位

你是專為國小〈年級〉學生製作教學簡報的簡報設計師。

請完全依照來源文件的逐頁設計製作簡報，**剛好 20 頁**，一頁對一頁，不可多、不可少、不可漏頁。

**視覺規範（20 頁必須完全一致）**
- 主色 #2F6DB5、輔色 #F5A623、強調色 #4CAF7D、背景 #FFFDF7、文字 #262626
- 標題字體 Noto Sans TC Bold，內文 Noto Sans TC Regular
- 插圖風格：溫暖手繪童書風，圓潤線條，明亮但不刺眼，無寫實照片
- 每頁左上角固定放「〈單元名〉」，右下角固定放頁碼
- 以上設定在全部 20 頁保持完全一致

**內容鐵律**
- 只能用來源文件的內容，不可自行增補任何課外知識、例子或數據
- 小試身手的題目與選項逐字照抄，不可改寫、不可給答案
- 版面文字照來源文件的字數，不可自行擴寫

**輸出品質**
請一頁一頁、一字一字仔細生成，並逐字確認，確保每個繁體中文字筆畫正確、清晰、無錯字，使用台灣用語。
````

〈提示詞〉區塊控制在 **400 字以內**，必須含：角色／任務／視覺規範／內容鐵律／輸出品質 五塊。

## 為什麼這樣寫（依據，不要隨便改）

| 設計 | 依據 |
|---|---|
| 一份提示詞 = 一次課 = 20 頁 | NotebookLM 簡報單次硬上限 20 頁（Free 8–15／Plus 20／Ultra 25） |
| 每份自帶全部內容 | 每次生成互相獨立、無記憶 |
| 詳盡設計當「來源」、短指令當「提示詞」 | 這是使用者實際的操作方式；也是公認降錯法——先產大綱、再以大綱為唯一來源生成 |
| 沒有講者備註欄 | 產出是連續圖片／PDF，沒有備註可放 |
| 版面文字硬性字數上限 | 投影片是算圖產生的圖片，中文字是「畫」出來的。少字＝少錯 |
| 選 Presenter Slides 而非 Detailed Deck | 版面字少 → 繁中錯字機率大幅下降 |
| 指定 hex 色碼＋字體名＋「20 頁保持一致」 | 12–20 頁之間配色與字體會漂移，寫死數值才壓得住 |
| 圖用「繪製描述＋課本圖號」 | NotebookLM 用 Nano Banana Pro 算圖，**無法插入來源檔裡的圖**。改成重繪＋標頁碼，匯出 PPTX 後可手動換原圖 |
| 結尾「一頁一頁、一字一字…逐字確認」 | 實測有效降低繁體中文糊字與錯字的通用咒語 |

## 生成後修不好的話

- 單頁重生：在該頁下方輸入修訂指令，全部輸入完再一次「生成修訂版簡報」
- 中文字糊掉修不動：匯出 PPTX 後用 PowerPoint 蓋色塊＋補文字框
- 整體崩掉：把版面文字再砍短一輪重生，通常是字太多造成的
