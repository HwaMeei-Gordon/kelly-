# S4 產出格式：來源檔 ＋ 共用提示詞

N 次課產出 **N+1 個檔案**：

```
第1次上課_來源.md   ← 純內容，整份直接上傳 NotebookLM
第2次上課_來源.md   ← 同上
…（每次課一份）
提示詞（共用）.md    ← 只有一份，N 次課共用
```

**不要把兩者合成一個檔。** 使用者要的是「上傳的檔案不用挑、不用剪貼」。

---

## 逐頁格式（每頁只有四個欄位）

````markdown
### 第 N 頁
- **課本頁數**：P.XX
- **內容排版**：
  - 【標題】〈≤14 字〉
  - 【主文】〈一句話 ≤30 字；沒有就省略這行〉
  - 【條列】
    1. 〈≤20 字〉
    2. 〈≤20 字〉
    3. 〈≤20 字〉
- **插圖引用**：〈畫面繪製描述：有什麼元素、怎麼排、什麼顏色〉（引用課本 P.XX 圖XX-X）
````

### 鐵律

- 順序固定：**頁數 → 課本頁數 → 內容排版 → 插圖引用**，四欄之外不准多欄
- **不可以有「講者備註」**，也不可用「備註」「補充說明」「教學提示」等別名偷渡。產出是連續圖片／PDF，沒有備註欄
- 標題 ≤14 字；條列最多 4 條、每條 ≤20 字；主文最多一句 ≤30 字
- 字少是硬要求 —— NotebookLM 的中文字是算圖「畫」出來的，字多就糊
- 沒有插圖的頁，〈插圖引用〉寫「無」；課本沒有的圖不准無中生有
- 每一頁都要標課本頁數；跨頁的複習頁寫 `P.XX、P.XX` 或 `P.XX－P.XX`
- 小試身手題目與選項**逐字照抄**，不改寫、不簡化、**不給答案**
- **小試身手頁豁免字數上限**，逐字照抄優先。在檔頭寫明豁免哪兩頁

## 來源檔骨架 `第N次上課_來源.md`

````markdown
# 〈單元名〉‧ 第N次上課 ‧ 〈本次主題〉

本文件為簡報的逐頁設計，共 20 頁。

**課程**：〈版本〉〈科目〉〈年級〉‧〈單元〉‧〈本次活動〉
**課本範圍**：P.XX – P.XX（小試身手在 P.XX）
**總頁數**：20 頁（第 1 頁到第 20 頁，連續無跳號）
**逐字照抄**：第 XX、XX 頁為小試身手，題目與選項逐字照抄課本 P.XX，該兩頁不受版面字數上限限制。

### 第 1 頁
- **課本頁數**：P.38
- **內容排版**：
  - 【標題】澆水就復活了
  - 【條列】
    1. 根吸收土壤裡的水分
    2. 莖把水送到植物體全身
- **插圖引用**：三格連續畫面，以綠色箭頭相連——左：盆栽枯萎下垂、葉片捲曲發黃；中：水壺往盆裡澆水；右：同一盆挺立翠綠、黃花朝上。（引用課本 P.38 圖38-1）

### 第 2 頁
（同上結構，一路寫到第 20 頁，一頁都不能省略）

**頁數檢查**：第 1 頁 – 第 20 頁，連續無跳號，共 20 頁 ✓
````

**到此為止 —— 來源檔就結束了，後面不要再接任何東西。**

## 提示詞檔骨架 `提示詞（共用）.md`

只產一份，N 次課共用。控制在 **400 字以內**。

````markdown
# NotebookLM 提示詞（N 次課共用）

> 貼進 NotebookLM「簡報 → 自訂」的提示詞欄位。格式選 Presenter Slides、語言選繁體中文。
> N 次上課都用這一段，不用改。

---

- **角色**：你是專為國小〈年級〉學生製作教學簡報的簡報設計師。
- **任務**：完全依照來源文件的逐頁設計製作簡報，剛好 20 頁，一頁對一頁，不可多、不可少、不可漏。
- **視覺規範（20 頁必須完全一致）**：
  - 主色 #2F6DB5、輔色 #F5A623、強調色 #4CAF7D、背景 #FFFDF7、文字 #262626
  - 標題字體 Noto Sans TC Bold，內文字體 Noto Sans TC Regular
  - 插圖為溫暖手繪童書風、圓潤線條、明亮不刺眼、無寫實照片
  - 每頁左上角固定放「〈單元名〉」，右下角固定放頁碼
  - 以上設定在全部 20 頁保持完全一致
- **內容鐵律**：
  - 只能用來源文件的內容，不可自行增補
  - 小試身手的題目與選項逐字照抄，不可改寫、不可給答案
  - 版面文字照來源文件的字數，不可自行擴寫
- **輸出品質**：請一頁一頁、一字一字仔細生成並逐字確認，確保每個繁體中文字筆畫正確、清晰、無錯字，使用台灣用語。
````

必含五塊：角色／任務／視覺規範／內容鐵律／輸出品質。

## 為什麼這樣寫（依據，不要隨便改）

| 設計 | 依據 |
|---|---|
| 一份來源檔 = 一次課 = 20 頁 | NotebookLM 簡報單次硬上限 20 頁（Free 8–15／Plus 20／Ultra 25） |
| 每份來源檔自帶全部內容 | 每次生成互相獨立、無記憶 |
| 來源檔純內容、不混說明 | 整份會被當成來源讀進去，說明文字會被畫成投影片內容 |
| 提示詞只產一份 | 角色／視覺規範／鐵律都與課次無關，複製 N 份只會 N 倍的維護成本 |
| 沒有講者備註欄 | 產出是連續圖片／PDF，沒有備註可放 |
| 版面文字硬性字數上限 | 投影片是算圖產生的圖片，中文字是「畫」出來的。少字＝少錯 |
| 選 Presenter Slides 而非 Detailed Deck | 版面字少 → 繁中錯字機率大幅下降 |
| 指定 hex 色碼＋字體名＋「20 頁保持一致」 | 12–20 頁之間配色與字體會漂移，寫死數值才壓得住 |
| 詳盡設計當來源、短指令當提示詞 | 這是使用者的實際操作方式；也是公認降錯法——先產大綱、再以大綱為唯一來源生成 |
| 圖用「繪製描述＋課本圖號」 | NotebookLM 用 Nano Banana Pro 算圖，**無法插入來源檔裡的圖**。改成重繪＋標頁碼，匯出後可手動換原圖 |
| 結尾「一頁一頁、一字一字…逐字確認」 | 實測有效降低繁體中文糊字與錯字的通用咒語 |

## 生成後修不好的話

- 單頁重生：在該頁下方輸入修訂指令，全部輸入完再一次「生成修訂版簡報」
- 中文字糊掉修不動：匯出 PPTX 後用 PowerPoint 蓋色塊＋補文字框
- 整體崩掉：把版面文字再砍短一輪重生，通常是字太多造成的
