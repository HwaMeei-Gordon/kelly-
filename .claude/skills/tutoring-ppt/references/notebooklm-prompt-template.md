# S4 NotebookLM 提示詞模板

每次上課產一份，檔名 `第N次上課_提示詞.md`。
每份**完全獨立、自帶全部內容**，不可出現「同上」「見前一份」「延續」。

---

## 檔案結構（三段）

```
【使用說明】  ← 給老師看的操作步驟，不會餵給 AI
【A. 短指令】 ← 貼進 NotebookLM「自訂提示詞」欄位
【B. 逐頁規劃】← 這份檔案整個上傳當唯一來源
```

---

## 完整模板（逐字照抄，`〈〉` 內替換）

````markdown
# 〈單元名〉‧ 第N次上課 ‧ NotebookLM 簡報提示詞

## 【使用說明】（老師看的，不要貼給 AI）

1. NotebookLM 開**新筆記本**（每次上課各開一個，不要共用）
2. 只上傳**這一個檔案**當來源 — 不要同時放課本照片，會抓錯
3. 點「簡報」→「自訂」
4. 格式選 **Presenter Slides**、語言選 **繁體中文**
5. 把下面〈A. 短指令〉整段貼進自訂提示詞欄位 → 生成
6. 逐頁檢查中文字，糊掉／錯字就在該頁下方輸入修訂指令，最後一次「生成修訂版簡報」
7. 匯出 PPTX，需要的話再手動換上課本原圖

---

## 【A. 短指令】← 複製這一整段貼進自訂提示詞欄位

你是專為國小〈年級〉學生製作教學簡報的頂尖簡報設計師。

請完全依照來源文件中的〈B. 逐頁規劃〉製作簡報，**剛好 20 頁**，一頁對一頁，
不可以自己加入任何觀點，也不可以漏掉任何一頁、多出任何一頁。

**視覺規範（20 頁必須完全一致，不可變動）**
- 主色 #2F6DB5、輔色 #F5A623、強調色 #4CAF7D、背景 #FFFDF7、文字 #262626
- 字體：標題 Noto Sans TC Bold，內文 Noto Sans TC Regular
- 插圖風格：溫暖手繪童書風，圓潤線條，明亮但不刺眼，無寫實照片
- 每頁左上角固定放「〈單元名〉」，右下角固定放頁碼
- 以上設定在全部 20 頁保持完全一致

**內容鐵律**
1. 只能使用來源文件裡的內容。課本以外的知識、數據、例子、比喻，一個字都不准加
2. 「小試身手」的題目、選項、步驟必須**逐字照抄**，不可改寫、不可簡化、**不可給答案**
3. 版面文字越精簡越好：標題 ≤14 字，每頁條列 ≤3 條，每條 ≤16 字
4. 詳細講解一律放「講者備註」，不要放到版面上
5. 圖片依規劃中的〈繪製描述〉重畫，並在圖片下方標註來源頁碼

**輸出品質**
請一頁一頁、一字一字仔細生成，並逐字確認，
確保每個繁體中文字筆畫正確、清晰、無錯字，使用台灣用語。
````

## 為什麼這樣寫（依據，不要隨便改）

| 設計 | 依據 |
|---|---|
| 一份提示詞 = 一次課 = 20 頁 | NotebookLM 簡報單次硬上限 20 頁（Free 8–15／Plus 20／Ultra 25） |
| 每份自帶全部內容 | 每次生成互相獨立、無記憶 |
| 選 Presenter Slides 而非 Detailed Deck | 版面字少 → 繁中錯字機率大幅下降；且本來就是老師講、不是給人自己讀 |
| 版面文字長度硬性上限 | 投影片是算圖產生的圖片，中文字是「畫」出來的。少字＝少錯 |
| 細節塞講者備註 | 版面保持乾淨，內容不流失 |
| 指定 hex 色碼＋字體名＋「20 頁保持一致」 | 12–20 頁之間配色與字體會漂移，寫死數值才壓得住 |
| 提示詞檔當**唯一**來源上傳 | 來源越雜抓錯率越高。先產大綱、再以大綱為唯一來源生成，是公認降錯法 |
| 圖用「繪製描述＋出處標註＋可換原圖」 | NotebookLM 用 Nano Banana Pro 算圖，**無法插入來源檔裡的圖**。所以改成重繪＋標頁碼，匯出 PPTX 後可手動換原圖 |
| 結尾「一頁一頁、一字一字…逐字確認」 | 實測有效降低繁體中文糊字與錯字的通用咒語 |

## 生成後修不好的話

- 單頁重生：在該頁下方輸入修訂指令（例：「把標題改成置中」「這頁的字重新畫清楚」），全部輸入完再一次「生成修訂版簡報」
- 中文字糊掉修不動：匯出 PPTX 後直接用 PowerPoint 蓋色塊＋補文字框
- 整體崩掉：把版面文字再砍短一輪重生，通常是字太多造成的
