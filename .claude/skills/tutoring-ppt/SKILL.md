# 家教教學簡報產線（Textbook → NotebookLM）

把「一疊課本照片」變成「每次上課各一份、可直接貼進 NotebookLM 就跑出 20 頁簡報」的提示詞。
全程在**同一個對話**跑完，不要求使用者切換視窗或分段餵料。

## 使用者只需要給兩件事

1. **課本內容** — Google Drive 資料夾連結（照片／PDF／掃描檔都可以）
2. **上課次數 N** — 例如「這單元分 2 次上」

其他一律不要追問。缺這兩項才問；其餘（年級、版本、科目）自己從課本畫面判讀，判讀不出來再一次問完。

## 硬性事實（先記住，會影響所有決策）

| 事實 | 影響 |
|---|---|
| NotebookLM 簡報**單次上限 20 頁**（Free 8–15／Plus 20／Ultra 25），是產品硬限制不是建議值 | 1 次上課 = 1 次生成 = 1 份獨立提示詞。**不可以**把 2 次課寫進同一份提示詞 |
| NotebookLM 每次生成**沒有記憶**、彼此獨立 | 每份提示詞必須**自帶全部所需內容**，不能寫「同上」「延續前一份」 |
| 投影片是 Nano Banana Pro **算圖產生的圖片**，不是可編輯圖層 | 它**無法插入課本原圖**。要求「直接用課本圖片」在 NotebookLM 是做不到的 → 改用 §圖片策略 |
| 同上，繁體中文是「畫」出來的，**容易糊掉、缺筆畫、寫錯字** | 版面文字必須極簡。少字＝少錯 |
| 產出是**連續圖片／PDF**，沒有備註欄 | **絕對不可以有「講者備註」欄位**，也不可用「備註」「補充說明」「教學提示」等別名偷渡回來 |
| 來源檔越雜，抓錯率越高 | 產出的提示詞檔要當作 NotebookLM 的**唯一來源**上傳，不要同時放課本照片 |

## 流程

```
讀 Drive 課本 → S1 原文還原 → S2 重點提煉 → S3 切課次＋逐頁規劃 → S4 產出 N 份提示詞 → 存回 Drive
```

S1–S3 一次跑完，中間不要停下來問「可以繼續嗎」。只有在 S3 發現內容量塞不進 N×20 頁時才中斷回報。

### S4 一律用 Workflow 平行跑

使用者已明確要求：**這條產線的 S4 每次都用 Workflow 平行執行，不需要再問**。

N 次課彼此獨立，天生適合平行。用 `pipeline()` 而非 `parallel()` — 每次課產生完就立刻接自己的驗收 agent，不必等其他次課。

```
pipeline(SESSIONS,
  s   => agent(產生第 s.n 次的提示詞, {phase:'Generate'}),
  (g,s) => agent(驗收第 s.n 次並直接修好, {phase:'Verify'}))
```

- 每個 generate agent 讀 `00_課本原文還原.md`（唯一內容真實來源）＋ `02_PPT分頁規劃.md`（自己那次課的 20 頁安排），寫出 `第N次上課_提示詞.md`
- 每個 verify agent 對照 00 逐項比對，**發現問題直接用 Edit 修好再複驗**，不是只回報
- 規模：N 次課 → 2N 個 agent。三次課就是 6 個，遠低於上限

各階段的輸出格式**逐字照抄** `references/stage-formats.md`。
S4 的提示詞模板**逐字照抄** `references/notebooklm-prompt-template.md`。

### S1 課本原文還原

逐頁把課本完整還原成文字。鐵律：

- 開頭第一行固定寫：`> 這是由AI深度看完每一頁課本所提煉的完整課本內容`
- **只寫當前頁**。照片常拍到隔壁頁的一角，要辨識出來並排除，不可混進來
- **不漏、不加**。課本沒有的知識、例子、補充，一個字都不准加
- 標題／內文／圖片／圖說／表格／小試身手 全部要有
- 字跡不清就標 `［不清：？］`，**絕對不要猜**
- 每一頁都要標頁碼，圖要編號（`圖24-1`），後面 S3、S4 全靠這個編號對圖

### S2 教學重點提煉

從 S1 的原文提煉「每個段落最核心要教的內容」。

- 依**課本原順序**分主題，不可重排、不可合併跳躍
- 100% 來自課本，零補充、零延伸
- 每個主題要標對應頁碼與對應的小試身手題號

### S3 課次切分＋逐頁規劃

把 S2 的主題切成 N 次課，每次課排成剛好 20 頁。

- **切點要落在主題邊界**，不可把一個概念切成兩半跨課
- 每次課的 20 頁結構建議：封面 1／本次目標 1／內容 13–15／小試身手 2–4／小結 1
- **小試身手獨立佔頁**：題目與選項與步驟必須與課本完全一致，逐字照抄，不改寫、不給答案。題目多可拆連續兩頁，但一樣計入 20 頁
- **實驗一律排除**，除非是「晚上在房間內、用簡易生活用品就能完成的超安全小實驗」
- 每頁都要指定：課本頁數、標題、版面文字、插圖（含對應課本圖號）
- 頁數不多不少剛好 20。排完自己數一遍

**塞不下怎麼辦**：如果內容量明顯超過 N×20 頁，不要硬壓縮也不要偷刪小試身手。停下來告訴使用者「建議改成 N+1 次」並附上兩種切法的比較，讓他決定。

### S4 產出 N 份 NotebookLM 提示詞

每次上課一份，各自獨立、自帶全部內容。照 `references/notebooklm-prompt-template.md` 的模板寫。

檔名：`第1次上課_提示詞.md`、`第2次上課_提示詞.md`…

**每份檔案有且只有兩個大區塊**，對應使用者的實際操作：

```
【一】資料來源文件 → 整段複製，貼進 NotebookLM 當「來源」
【二】提示詞       → 另外複製，貼進「提示詞」欄位（≤400 字）
```

**每頁只有四個欄位**，不多不少：頁數 → 課本頁數 → 內容排版 → 插圖引用。
字數上限：標題 ≤14 字、條列最多 4 條每條 ≤20 字、主文 ≤30 字。

### 圖片策略（取代「直接用課本圖片」）

NotebookLM 沒辦法插入課本原圖，所以〈插圖引用〉欄用兩段寫法：

1. **繪製描述** — 把課本那張圖的畫面、元素、標示、配色寫清楚，讓 AI 重繪出接近的圖
2. **課本出處** — 結尾標「（引用課本 P.28 圖28-2）」，上課時可以直接叫學生翻課本對照；匯出 PPTX 後也能照這個標註手動換上掃描原圖

課本沒有的圖，**不准無中生有**。寧可那頁只有文字，〈插圖引用〉寫「無」。

## 存檔位置（Google Drive）

存回課本資料夾的**上一層**（單元資料夾），不要塞進 `課本/` 裡：

```
📁 <單元資料夾>/
├── 📁 課本/                      ← 使用者放的原始照片（不動它）
├── 00_課本原文還原.md
├── 01_教學重點整理.md
├── 02_PPT分頁規劃.md
└── 📁 03_NotebookLM提示詞/
    ├── 第1次上課_提示詞.md
    └── 第2次上課_提示詞.md
```

Drive 工具是 deferred 的，用 ToolSearch 載入 `search_files` / `create_file` / `read_file_content` / `download_file_content`。
建資料夾與檔案前先確認父資料夾 `canAddChildren: true`。

## 交付給使用者時要附的操作 SOP

產出後，用這幾句話告訴使用者怎麼用（不要只丟檔案就結束）：

1. NotebookLM 開一個**新筆記本**（每次上課各開一個，不要共用）
2. 把檔案裡的〈【一】資料來源文件〉整段複製，貼進去當**唯一來源** — 不要同時放課本照片，會抓錯
3. 點「簡報」→「自訂」
4. 格式選 **Presenter Slides**（簡報者模式，字少版面乾淨）、語言選**繁體中文**
5. 提示詞欄位貼上檔案裡的〈【二】提示詞〉那一段
6. 生成後逐頁檢查中文字，有糊掉或錯字就在該頁下方輸入修訂指令，最後一次「生成修訂版簡報」
7. 匯出 PPTX／PDF，需要的話再照插圖引用的頁碼手動換上課本原圖

- [ ] 每頁四欄位齊全且順序正確：課本頁數 → 內容排版 → 插圖引用
- [ ] 每頁都標了對應的課本頁數
- [ ] 小試身手題目與 S1 原文逐字比對一致，沒有給答案
- [ ] 沒有任何課本以外的知識、數據、例子混進去
- [ ] 每張圖都有對應的課本圖號，且該圖號真的存在於 S1，沒有憑空捏造的圖
- [ ] 實驗都符合篩選規則
- [ ] 每份提示詞都能單獨使用，沒有「同上」「見前一份」這種依賴
